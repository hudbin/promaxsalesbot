PROMAX KUNLIK HISOBOT BOTI
==========================
Barcha ma'lumot AinurPOS'dan olinadi. Botda hech narsa kiritilmaydi.

O'RNATISH
---------
1. BotFather: /setprivacy → botni tanlang → Disable.
2. config.py:
   BOT_TOKEN   = "..."          ← BotFather tokeni
   AINUR_TOKEN = "sk_..."       ← AinurPOS → Integratsiyalar → Connect API
                                  (ACCESS: Readonly yoki RO + Orders → Saqlash)
3. start.bat ni ishga tushiring. Oynada har bir bo'lim holati chiqadi:
   AinurPOS API · Savdo: ✅   · Qaytarish: ✅   · Mijozlar/qarz: ✅
4. Botni guruhga qo'shib ADMIN qiling, guruhda: /ulash
   Kompyuter yonganda avtomatik ishga tushishi uchun: avtostart.bat ni BIR MARTA bosing.
   Kompyuter uyqu rejimiga o'tmasin: Параметры → Система → Питание → Сон: Никогда.
5. Tekshirish: botda yoki guruhda /api

DAFTAR REJIMI (AinurPOS faqat ombor uchun)
------------------------------------------
Bir martalik o'tish: kun oxirida, savdo tugagach botda  /kochir  → «Ha».
AinurPOS'dagi mijozlar va qarzlar botga BOSHLANG'ICH QOLDIQ qilib ko'chiriladi.
Shundan keyin:
  • savdo, to'lov, qarzdorlik, kassa — botning o'z bazasida (daftar);
  • har bir savdo AinurPOS'ga chiqim hujjati bo'lib navbat bilan yuboriladi,
    shuning uchun ombor qoldig'i o'zi kamayadi (token ACCESS = «RO + Orders»);
  • AinurPOS o'chiq bo'lsa savdo navbatda turadi va ulanish tiklangach ketadi;
    yuborilmaganlar soni kunlik hisobotda ⚠️ bilan ko'rsatiladi;
  • qarz to'lovini AinurPOS'ga qo'lda kiritish KERAK EMAS.

MIJOZ QIDIRUVI
--------------
Mini app'da «Mijozni tanlang» → qidiruv maydoni. Botda ism yozib yuborsangiz ham
qidiradi. Apostrof, kirill/lotin va x/h farqi hisobga olinmaydi:
«oga» → OG'A, «xorazm» → Хоразм, «qoqon» → Qo'qon. Telefon bo'yicha ham qidiradi.

DO'KONLAR
---------
config.py → DOKONLAR = ["Sklad", "Magazin"]
Mini app'da faqat shu do'konlar ko'rinadi, shu tartibda. Boshqalari (Terminal
va h.k.) yashiriladi. Ro'yxatni bo'sh qoldirsangiz — hammasi ko'rinadi.
Qoldiq baribir barcha do'konlar kesimida ko'rsatiladi.

MINI APP — SOTUV (sinov rejimi)
-------------------------------
Shart: AinurPOS → Connect API → token ACCESS = «RO + Orders» (Readonly bilan
sotuv yaratilmaydi). Sotuv AinurPOS'ga to'g'ridan-to'g'ri yoziladi.

Ishga tushishi: start.bat cloudflared.exe ni o'zi yuklab oladi va HTTPS manzil
yasaydi. Oynada "Mini app manzili: https://...trycloudflare.com" chiqadi.
Keyin botda /start bosing — menyuda «🛒 Sotuv (mini app)» tugmasi paydo bo'ladi.

Mini app ichida:
  🛒 Sotuv      — tovar qidirish (qoldiq va narx ko'rinadi) → savat → mijoz,
                  to'langan summa va turi → AinurPOS'ga yuboriladi.
  💳 Qarz to'lovi — botda qayd qilinadi va guruhga tushadi. API metodi yo'qligi
                  uchun AinurPOS'ga QO'LDA kiritiladi; guruhdagi
                  «✅ AinurPOS'ga kiritdim» tugmasi bilan belgilanadi.
  📦 Ombor      — do'kon qoldig'i.

DIQQAT: manzil har safar bot qayta ishga tushganda o'zgaradi (bepul tunnel).
Doimiy manzil uchun server kerak — unda config.py dagi MINI_URL to'ldiriladi.
To'lov turi nomlari config.py → TOLOV_API da; AinurPOS boshqa nom kutsa,
shu yerda tuzatiladi.

RASXOD MODULI
-------------
🧾 Rasxod qo'shish (yoki /rasxod):
  summa (faqat raqam) → kategoriya (tugmalar) → izoh (qo'lda yoziladi yoki
  «⏭ O'tkazib yuborish») → tasdiqlash. Saqlangach guruhga ham tushadi.
  Xato kiritilsa «❌ Bekor qilish» tugmasi (o'zi kiritgan yoki guruh admini).
Kategoriyalar: /kategoriya — ro'yxat, 🗑 bilan olib tashlash.
  Tez qo'shish: /kategoriya Kommunal
  Standart: Obed, Alohida rasxod, Transport, Boshqa.
Rasxodlar AinurPOS'da emas, botning promax_hisobot.db faylida saqlanadi
(jadval: rasxod — id, sana, vaqt, summa, kategoriya, izoh, kim, kim_id, bekor).
Hisobotda: Sotuv − Rasxod = Sof foyda; har bir rasxod izohi bilan + Excel varag'i.

BOT MENYUSI (shaxsiy chatda /start)
-----------------------------------
📊 Bugungi hisobot — savdo, mijozlar, qarz to'lovlari, tushum, qarzdorlik
📆 Davr hisoboti   — kecha / oxirgi 7 kun / shu oy / o'tgan oy (+ Excel)
👥 Mijozlar        — ro'yxat (qarzdorlar yuqorida), mijoz kartasi:
                     qarz, to'lanmagan hujjatlar, oxirgi xaridlar va to'lovlar.
                     Qidirish: mijoz ismini yozib yuboring.
📒 Qarzdorlik      — umumiy qarz, qarzdorlar ro'yxati, Excel (ochiq hujjatlar bilan)
Guruhda admin: /qarz

KIRIM-CHIQIM LENTASI
--------------------
AinurPOS'dagi har bir yangi hujjat LENTA_DAQIQA (3) daqiqa ichida guruhga tushadi:
🟢 kirim · 🔴 sotuv · ⚪ ichki chiqim (X / 0 so'm) · ↩️ mijozdan qaytarish ·
↪️ yetkazib beruvchiga qaytarish · 🔧 qoldiq tuzatish · 🗑 o'chirilgan hujjat.
Standart — hisobot guruhiga. Alohida guruhga: o'sha guruhda admin /lenta yozadi.
O'chirish: /lenta ochir. Birinchi ishga tushishda eski hujjatlar yuborilmaydi.

GURUHGA YUBORISH
----------------
- Har kuni HISOBOT_VAQTI da (20:00) kunlik hisobot guruhga avtomatik tushadi.
- Shanba kuni qo'shimcha haftalik (oxirgi 7 kun), har oyning 1-sanasi o'tgan oy
  hisoboti (config.py: HAFTALIK_KUN, OYLIK_HISOBOT).
- Shaxsiy chatdagi har bir hisobot va Qarzdorlik ostida «📤 Guruhga yuborish»
  tugmasi bor — faqat guruh adminlari bosa oladi.

Qarzdorlik AinurPOS savdo hujjatlari bo'yicha hisoblanadi (config.py:
QARZ_DAVRI_KUN — necha kunlik hujjatlar, standart 180).

HISOBOTDA NIMA BOR (har kuni HISOBOT_VAQTI da)
----------------------------------------------
- Sotuv: model, dona, narx (turli narxlar alohida), summa
- Mijozlar bo'yicha: sotuv, kassada to'langan, qarzga berilgan; sotuvchilar
- Qaytarishlar
- Eski qarz to'lovlari: mijoz, summa, turi (naqd/plastik/perechisleniya)
- Jami tushum turlar bo'yicha (savdodan + eski qarzdan)
- Qarzdorlik: jami, o'zgarish, qarzi kamaygan mijozlar, eng katta qarzdorlar
- Excel fayl

SOTUVCHILAR UCHUN QOIDA
-----------------------
- Har bir savdoni mijoz tanlab AinurPOS'da kiriting.
- Eski qarz to'lovini AinurPOS'da O'SHA QARZGA BERILGAN SAVDO HUJJATI
  bo'yicha, to'lov turini tanlab kiriting. Shunda bot uni aniqlaydi.
- Qarz to'lovlarini kuzatish bot API'ga ulangan birinchi kundan keyin
  boshlanadi (birinchi kun — boshlang'ich holat olinadi).
